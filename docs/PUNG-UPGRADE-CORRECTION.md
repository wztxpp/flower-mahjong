# 补杠时机纠正 / Pung-upgrade timing correction

本地候选改动，尚未推送或部署。纠正 v0.7.0 把“碰后不能马上补杠”误写成“永久不能补杠”的问题；同时保留可配置大单吊喜钱改动。

## 确认规则

- 刚碰完，还没有打出一张牌时，不能补杠。
- 打出一张牌后，之后轮到自己、满足现有合法操作条件时可以补杠。原先留在手里的同牌可用，不要求新摸到同牌。
- 暗杠、杠后补摸和胡牌都不代替这次必须的出牌。
- 不改变胡牌优先、胡后听口保持、抢杠、杠补摸来源、杠分和萝卜规则。同牌两组碰仍是两组，补其中一组不会合并；已有杠仍可加至八张。

## 状态和兼容

- 新局启用 `allowPungUpgrade: true` / `pungUpgradeAfterDiscard: true`。
- 每人 `pendingPungDiscard` 在碰成立时设为 true，实际出牌后为 false。状态随牌局保存，刷新不解除限制。
- 已有 v0.7.0 的 `allowPungUpgrade: false` 按修正后的“先出牌再补”解释。缺少新状态字段时，从本人最近一次碰/出牌事件推断，不因中间暗杠、摸牌而放行。
- 更早缺少限制字段或明确允许、且没有新时机规则的旧局保留原行为；下一局使用新规则。已打开的抢杠窗口不重建。
- 不重洗、不改手牌、不回滚历史操作、不重算分数。不增加客户端可修改规则或状态的接口。
