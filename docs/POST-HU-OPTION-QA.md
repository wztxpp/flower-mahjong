# 胡后自动打出开局选项：验证记录

验证日期：2026-11-05。代码以 GitHub `wztxpp/flower-mahjong` main `61b2d7f78fe693c9c2cadac0aa5e6ca7411ea504` 为基线；该远端提交在验证完成前再次核对未改变。本记录对应本地待发布修改，不代表线上已更新；未推送或部署。

## 行为

- 房主在第一局或同桌下一局开局前选择“胡后自动打出”，默认勾选。仅此布尔选项可以经开局 API 设置，不开放其他计分规则。
- 不勾选时，胡后的正常摸牌、续摸和杠后补摸没有胡、杠可选也会等待“过”；服务端只接受过来打出新牌，旧客户端直接发出牌不能跳过。原手牌仍固定。
- 可胡时保留胡/过；没有胡且有合法杠时仍必须杠。勾选时保留自动打出行为，不自动胡或杠。
- 本局选项保存于游戏规则，开局后不能修改。重连、服务重启和三名玩家看到的设置一致。旧局缺少该字段继续自动，schema1/2 引擎未修改。
