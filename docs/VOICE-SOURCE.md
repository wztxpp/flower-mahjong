# 麻将角色语音来源与验证

## 真实生成文件（2026-11-03 基础集）

2026-11-03 生成三套原创中文角色音色：甜萌萝莉音 `sweet`、沉稳御姐音 `elegant`、明亮阳光少女音 `sunny`。每套含一至九条、一至九筒、碰、胡、杠，共 21 条；总计 63 个 MP3，约 85 秒、1.09 MB。

文件位于 `public/voices/<角色>/<报牌>.mp3`。`manifest.json` 包含原文、路径、音色方向、参考录音种子、来源、时长、哈希及审查边界。网页播放这些预先生成的音频，不依赖浏览器系统 TTS。

## 来源与方法

沿用[《十二证词》的已核实本地配音方法](https://github.com/wztxpp/twelve-alibis/blob/dc8c1cdb81eaa4d1c7a47dd4c3432c1177580723/docs/AUDIO-SOURCE.md)：

- 代码：[QwenLM/Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)，`qwen-tts==0.1.1`。
- 原创音色：[Qwen3-TTS-12Hz-1.7B-VoiceDesign](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign)，修订 `5ecdb67327fd37bb2e042aab12ff7391903235d3`。
- 同角色连续报牌：[Qwen3-TTS-12Hz-0.6B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base)，修订 `5d83992436eae1d760afd27aff78a71d676296fc`。
- 三组不同方向先生成原创参考录音，再用相应参考生成该角色所有报牌。没有简单升降调伪装成三个人。
- 全程使用现有 CPU 本地推理，无购买、充值、付费 API 或信用卡试用。权重下载后，生成以离线模式运行。
- 模型卡与官方代码标注 Apache-2.0；此处说明工具与权重来源，不对生成作品的独占权或不侵权作保证。
- 三个声音均为虚构成年角色风格，没有使用真人、演员、明星或未成年人的声音样本。

生成工具和复现方法位于 `scripts/voices/`。模型权重、Python 虚拟环境和中间 WAV 不随网页发布。成品为 24 kHz 单声道、96 kbps MP3；FFmpeg loudnorm 目标 -18 LUFS、-2 dBTP。

## 完成的检查

- 63 个文件全部存在，路径覆盖正确，哈希各不相同。
- 全部 MP3 成功解码；检查时长、静音、有限采样值及削波比例。
- 对所有成品 MP3 用本地 faster-whisper small、中文、CPU int8、beam_size=5 逐条转写。
- 另外用 faster-whisper medium 对三套完整的 21 条序列做上下文转写，片段间插入 0.35 秒静音，并使用麻将词汇提示。
- 自动检查与原始逐条结果见 `voice-audit.json`；上下文结果、音频哈希及明确的不确定项见 `voice-context-audit.json`。
- `tests/voice-assets.test.js` 通过 2 项发布资源测试。

## 未通过确认的边界

**没有完成人工主观试听，不能宣称音色表演、每个声调或发音完全正确。**短音节 ASR 会混淆同音字、漏识别，甚至产生无关文字，所以不能把逐条转写当作音频真值。

甜萌声线的“胡／杠”最初在两轮单字候选中识别不稳定。最后使用同一原创参考声音生成“麻将。胡！”和“麻将。杠！”，依据波形静音和词时间戳仅截取目标报牌。最终完整序列识别为“碰 壺 杠”，与目标碰／胡／杠的普通话发音一致。未截取载体句的孤立目标曾出现低置信度结果，因此该结果仍不构成人工发音认证。

阳光声线的“九筒”也使用相同方法修复。未截取的完整载体句识别为“麻将／酒桶”，后两字与“九筒”同音；截取后的完整序列却识别为“球桶”。目标起止处均位于静音区，没有保留“麻将”或切掉目标开头。该条仍在清单中明确标为 `uncertain`，保留识别差异，不冒充完全确认。

三条修复的生成文本、种子、载体哈希、ASR 词时间戳、静音区间和截取边界均在 `voice-rescue-audit.json`。其余报牌的序列识别主要为数字写法或同音字差异，也不等于人工认证。若后续试听确认需要改动，重新生成对应片段后必须重新跑检查；旧上下文审查只在音频哈希仍匹配时才会复用。
