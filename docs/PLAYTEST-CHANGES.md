# 试玩反馈与修订边界

日期：2026-11-03。所有分数都是本局虚拟积分。

## 已核实的旧版问题

- 胡过后仍能打任意手牌：已在旧版引擎内存局面复现，属于服务端合法动作限制缺失，不只是按钮问题。
- 普通摸牌需要手点，成功操作后还立即再发一次完整查询；轮询每次响应后再等一秒。修订自动摸牌、权威操作响应复用、轻量版本查询和自适应轮询。
- 没有个人胡牌区；自摸实体和牌只保存在后台，接炮仅在出牌者牌河打“胡”标记。
- 未实现即时杠分、第五张杠、三家都胡即结束、胡杠同时出现只给胡、胡过后的出牌不可碰。
- 原先碰与明杠同级；最新明确规则是胡优先、杠高于碰、同级顺位最近者优先，且必须等所有可回应者操作完。

## 萝卜反馈：未证实旧版数据丢失

旧版每次合法杠已立即追加一张萝卜，首次胡再追加六张，并没有清空旧萝卜。用守恒的内存牌局验证，一杠后首胡为七张、两杠后首胡为八张；胡牌日志只显示“本次新翻六张”，与总数容易混淆。本次补充累计展示与回归测试，不能把用户那局未经定位的“少萝卜”直接判定为同一原因，也不能将总数硬编码为八。

## B 的胡牌按钮问题：原现场仍未定位

用户报告 B 有筒子可胡但未出现按钮。没有该局的房号或当时截图，不能确认具体牌值、手牌、碰杠、叫牌锁、出牌者保护和响应状态。没有读取其他房间的暗牌来猜测。

新增自己的胡牌诊断和正反例测试，区分牌型、重复胡锁、受保护出牌、回合和已回应状态；它们不证明原现场已经复现或根因已解决。诊断只出现在本人的授权视图，不公开对手暗牌。历史私密摸牌不记录具体牌面，因此走过的局面未必能仅凭日志还原。

## 尚待按实际桌规调整

- 萝卜先按各自的杠累计，不替其他玩家累计；“所有杠”是否全桌共享尚不明确。
- 四张同牌加一番，五张加两番；六张以上同牌不推导新的加番表。神龙六/七/八张十分/二十/四十分保留为另一项。
- “对子牌型”的额外番没有明确口述数值，不另加。七对是否作为可胡牌型，与是否额外加番是两件事。
- 大单钓先按胡前只剩一张暗手牌判定，每家固定五十分；与一般番分、萝卜、神龙如何叠加采用明确的可配置暂定处理。
- 同时能胡能杠只给胡；是否连“过”也禁止未明确，先允许放弃胡。
- 三家同时达到已胡条件，先完成同次所有胡牌与支付，再结束，不能提前终止第二位赢家。

## 版本安全

0.1 的已保存牌局使用保留的原引擎继续，不修改旧手牌、牌墙、积分或操作记录。新局使用 schemaVersion 2。数据库无需破坏式迁移；同一站点、同一表保留旧记录。新规则只在新局生效，不能声称旧局已经悄悄变成新规则。

## 杠后五筒漏提示的定向修复（v0.6.0）

2026-11-03 用户截图中“暂不”是玩家昵称。截图手牌为 5/6/7/7/8/8/8/9 条与 3/4/5/6/7 筒，听 2/5/8 筒，已胡五次；公开牌河圈出五筒，萝卜栏显示该玩家杠牌 +1。只读线上快照匹配了参与者、手牌、五次胡牌区及补杠二筒，但接口截断了完整历史，不能断言已重放原始事件的全部状态。

守恒测试重现了同样手牌在仍有重复接胡锁时，面对补杠后的五筒不进入回应阶段的问题。修复仅让服务端标记的实际杠后下一张弃牌绕过该接胡锁，同时统一合法按钮、诊断和结算三个检查；普通弃牌锁、胡过出牌方保护、付款、萝卜和实体牌守恒均不变。

不会回滚已发生的动作、补记漏胡分数或重开牌局。更新仅影响后续新生成的弃牌回应，已经缓存的回应列表和已经自动推进的历史不追溯更改。包含精确手牌、两种出牌者胡牌状态、四种锁配置、普通弃牌负向对照和三个独立 HTTP 客户端的重复请求测试。


## 杠后接炮付款修复（v0.6.1）

截图显示 1 号位杠后打出九筒，3 号位接胡时却由另外两家各付八分，收入十六分。这是实际付款方逻辑错误，不只是文字。schema 3 后续杠后接炮一律由真实出牌者单独支付；大单吊、已胡者再胡、一炮多响与终局均遵守此规则。真实自摸、杠后补摸、即时杠分、普通大单吊接炮及终局神龙维持原行为。已保存历史付款及积分不自动重算，schema 1/2 冻结引擎不变。

## 胡牌语音与胡后强制杠（v0.6.1）

每位角色补充真实“自摸”“放炮”音频。已确认的胡事件按服务端 source 判断，赢家先说分类再说“胡”；杠后接炮仍为放炮，杠后补摸为自摸。两句按同一组排队，防止队列淘汰或超时拆开，重连与重复事件不重播。

一炮双响原实现已固定按放炮者下家、再上家排序，不受两人点胡先后影响；本次只增加覆盖全部座位及终局的回归测试，没有改动正确顺序。

按用户更正，已经胡过且本次新牌不能胡时，存在合法暗杠、补杠或加第五张则必须选择杠，不再提供“过”或“出牌”。服务端也拒绝旧客户端发来的跳过/出牌请求；仍需玩家点击杠，不自动杠。真正可胡时的原有选择暂未改动。无合法杠时维持原自动摸打，旧schema1/2引擎不变。

## 六至八张加杠与明杠补摸付款（待发布）

确认扩展单组杠：四张后可逐张加到第五、六、七、八张；每次向另外两家各收 1 分，翻 1 张萝卜并补 1 张牌。每次仍检查牌墙至少两张、实体每种最多八张、胡后完整听口和必须杠规则。同牌不同副露保持独立。普通同牌七张加 4 番、八张加 5 番；七对首档及后续固定番不变。

明杠后的本次补摸胡，只向该次明杠的出牌者收胡牌分；自己摸起来的暗杠、补杠或加杠后本次补摸胡仍向另外两家收取。即时明杠费仍只向出牌者收 2 分；补杠费独立。新补摸保存对应杠的 type/fromSeat，普通续摸不继承这次来源。旧 schema 3 存档只在紧邻杠与补摸日志能可靠确定来源时恢复；不能确定的保留旧行为。历史已结算账不回写，schema 1/2 冻结引擎不改。
